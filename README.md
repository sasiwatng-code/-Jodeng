# จดเอง

จดรายรับรายจ่ายง่ายๆ แค่พิมพ์ เช่น `ซื้อของทำตู้ไฟ 500บาท` ระบบแยกจำนวนเงินและหมวดให้อัตโนมัติ

- สรุปรายวัน / สัปดาห์ / เดือน / ปี / ช่วงวันที่เอง (กราฟวงแหวน)
- ระบบยืม-คืนเงิน แยกชื่อคน นับจำนวนวันที่ยืม
- เพิ่มหมวดและคำสำคัญเองได้
- ติดตั้งเป็นแอปบนมือถือได้ (PWA) ใช้งานออฟไลน์ได้
- ข้อมูลเก็บในเบราว์เซอร์ของเครื่องนั้น

## วิธีขึ้น GitHub Pages
1. สร้าง repository ใหม่ชื่อ `jodeng` (หรือชื่ออะไรก็ได้)
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ (index.html, manifest.webmanifest, sw.js, โฟลเดอร์ icons)
3. ไปที่ Settings → Pages → Source เลือก `Deploy from a branch` → Branch `main` / `(root)` → Save
4. รอ 1-2 นาที จะได้ลิงก์ `https://ชื่อผู้ใช้.github.io/jodeng/`

## ติดตั้งบนมือถือ
- **iPhone (Safari):** กดปุ่มแชร์ → เพิ่มลงในหน้าจอโฮม
- **Android (Chrome):** เมนู ⋮ → ติดตั้งแอป

## อัปเดตแอป
แก้ไฟล์แล้ว push ใหม่ และเปลี่ยนเลข `CACHE = 'jodeng-v1'` ใน `sw.js` เป็น v2, v3 ... เพื่อให้เครื่องที่ติดตั้งแล้วโหลดเวอร์ชันใหม่
